# Draft War Room

A free, installable draft assistant for fantasy football. It tracks your board in real time and answers the only question that matters when you're on the clock: **who do I pick right now?** Every recommendation is expert-backed (FantasyPros consensus), with live value-vs-ADP, tier and position-run alerts, and automatic injury flags.

Built as a personal, single-league tool — no accounts, no ads, no fees. Installs to your phone's home screen as a PWA and runs offline at the draft table.

> **Personal, non-commercial project.** Read-only use of public data for personal draft prep. Not affiliated with Yahoo, the NFL, or any data provider.

## Features

- **Best-available recommendations** — expert consensus board with a snake-draft-aware "on the clock" bar that names your pick.
- **Tier & position-run alerts** — warns when a tier drops to ≤2 players and when a position is running.
- **Value vs. ADP** — flags players falling past their average draft position, with a live "top values" panel.
- **Injury flags** — hurt players are badged (Q / O / IR …) automatically from the snapshot.
- **Roster + bye tracking**, fast one-tap check-off, undo/reset, search & filters.
- **Offline + autosave** — your board persists across refreshes and phone-locks; works with no signal.

## Quick start

```bash
npm install
npm run snapshot     # build today's players.json (see GET_STARTED for the API key)
npm run dev          # http://localhost:5173
npm run build        # production build in /dist
```

Full setup, deploy, and add-to-home-screen instructions are in **[GET_STARTED.md](GET_STARTED.md)**.

## Data sources

- [Fantasy Football Calculator](https://fantasyfootballcalculator.com/adp) — ADP (free REST API)
- [FantasyPros](https://www.fantasypros.com/api-data/) — consensus rankings & tiers (free API key)
- [Sleeper](https://docs.sleeper.com/) — live injury designations (free, no key)

## Tech

React + Vite, `vite-plugin-pwa` (offline service worker + installable manifest), `localStorage` persistence, `lucide-react` icons. No backend.
